# 신세벌 타자

**신세벌식 P2 자판을 처음부터 익히는 웹 타자 연습**

**바로 연습하기: https://kaorw.github.io/sebeol-type/**

![신세벌 타자 연습 화면](docs/screenshot.png)

신세벌식 P2는 Shift 없이 모아치기가 되는 세벌식 자판입니다. 오른손으로 첫소리를 치고, 왼손으로 가운뎃소리와 받침을 칩니다. 같은 왼손 키가 첫소리 바로 뒤에서는 홀소리로, 그다음에는 받침으로 바뀝니다(첫가끝 갈마들이). 그래서 처음 배울 때는 "지금 이 키가 무엇이 되는지"를 헷갈리기 쉽습니다.

신세벌 타자는 그 부분을 화면에서 짚어 줍니다. 칠 글자를 키 순서로 풀어서 보여 주고, 눌러야 할 키와 손가락을 함께 표시합니다. 기준 자리부터 한 줄씩 익혀 나가도록 연습을 이끕니다.

## 이런 분께

- 두벌식을 쓰다가 신세벌식 P2로 바꾸려는 분
- 신세벌식을 알지만 손가락 자리가 아직 몸에 붙지 않은 분
- 오쏘리니어·스플릿 키보드에서 세벌식을 연습하고 싶은 분

## 무엇을 해 주나

- **키와 손가락 안내**
  - 다음에 누를 키를 키보드 그림에 표시합니다.
  - 쓸 손가락을 손 그림에 표시합니다.
  - 틀린 키는 붉은 테두리로 알려 줍니다.
- **글자를 키 순서로 풀어 보기**
  - 예: `과` = `K`(초성 ㄱ) → `/`(오른쪽 ㅗ) → `F`(겹홀소리 ㅘ)
  - 갈마들이, 겹홀소리, 된소리 거듭치기, Shift가 필요한 곳마다 설명이 붙습니다.
- **기준 자리부터 줄 단위로 해금**
  1. 기준 자리: 홈 행 11키, 칠 수 있는 낱말 91개
  2. + 윗줄: 1,148개
  3. + 아랫줄: 5,545개(전체)
  - 열린 키가 모두 숙련도 80%에 닿으면 다음 줄이 열립니다.
  - 해금을 끄고 연습할 키를 직접 고를 수도 있습니다.
- **키별 숙련도**
  - 키마다 속도와 정확도를 따로 잽니다.
  - 가장 약한 키가 든 낱말을 더 자주 냅니다.
- **다양한 연습 글**
  - 낱말: 국립국어원 학습용 어휘에서 오래 안 나온 낱말부터 냅니다.
  - 짧은 글: 문장, 속담, 저작권이 끝난 한국 문학 등 232개가 있습니다.
  - 내 글감: 원하는 글을 붙여 넣어 연습할 수 있습니다. 붙여 넣은 글은 그 브라우저에만 저장됩니다.
- **통계:** 키별 숙련도 지도, 최근 연습의 속도와 정확도 그래프, 약한 키 목록을 봅니다.
- **키보드 모양:** 일반, 오쏘리니어, 스플릿, 트랙볼 스플릿 배열을 지원합니다. 손가락 배정도 모양에 맞게 바뀝니다.
  - 다음에 누를 키 위에 칠 손가락 이름(예: `왼검지`)이 붙습니다.
- **세모이 자판(모아치기):** 머리의 `자판`에서 `세모이`를 고르거나 주소에 `?scheme=semoe`를 붙입니다.
  - 한 글자의 초성·중성·받침 키를 한꺼번에 눌렀다 떼면 판정합니다.
  - 예: `과` = `K`(ㄱ) + `.`(겹홀소리 ㅗ) + `F`(ㅏ), `있` = `J` + `D` + `;`(ㅆ)
  - 글자 키와 스페이스를 함께 누르면 띄어쓰기까지 한 번에 칩니다.
  - 틀리면 방금 누른 키와 그 결과를 보여 줍니다.
  - 약어는 아직 다루지 않습니다.

## 쓰는 법

1. 실제 키보드가 있는 컴퓨터에서 [사이트](https://kaorw.github.io/sebeol-type/)를 엽니다.
2. 그냥 치면 됩니다. 판정은 **물리 키 자리**로 하므로 한/영 상태나 설치된 입력기와 상관없습니다. 신세벌식 입력기가 없어도 연습할 수 있습니다.
3. `Esc`를 누르면 새 글이 나옵니다.

- 연습 기록은 **이 브라우저에만** 저장됩니다. 로그인이나 서버 저장은 없습니다.
- 다른 기기나 브라우저에서는 처음부터 시작합니다.

## 신세벌식 P2 한눈에 보기

| 손 | 치는 것 | 키 |
|---|---|---|
| 오른손 | 첫소리(초성) | Y U I O P · H J K L ; ' · N M / |
| 왼손 | 받침(종성), 첫소리 바로 뒤에서는 가운뎃소리(중성) | Q W E R T · A S D F G · Z X C V B |

- **된소리:** 같은 첫소리 키를 두 번 칩니다. 예: `K K` = ㄲ
- **겹홀소리:** 오른쪽 `/`(ㅗ) `O`(ㅜ) `I`(ㅡ)로 시작합니다. 예: 과 = `K / F`, 워 = `J O R`, 의 = `J I D`
- **겹받침:** 받침 키를 이어서 칩니다. 예: 없 = `J R E Q`, 밖 = `; F C C`

배열 설계와 자세한 설명은 [팥알 님의 신세벌식 P2 글](https://pat.im/1136)을 참고하세요. 이 사이트의 입력 규칙은 [온라인 한글 입력기](https://ohi.pat.im/?ko=sin3-p2)에 같은 키를 친 결과와 대조해 확인했습니다. 옛한글과 기호 확장 배열은 다루지 않습니다.

## 개발

```bash
npm install
npm run dev      # 개발 서버
npm test         # 조합 엔진, 입력기 대조, 어휘·글감 전체 왕복 테스트
npm run build    # 정적 파일 → dist/
```

| 경로 | 내용 |
|---|---|
| `src/engine/` | 신세벌식 P2 조합 엔진 (키 → 글자, 글자 → 키 순서) |
| `src/layout/` | P2 배열, 물리 배열(일반/오쏘리니어/스플릿)과 손가락 배정 |
| `src/app/` | 출제, 숙련도, 글감(`texts.ts`), 내 글감 |
| `src/main.ts` | 화면 |
| `data/` | 정제된 어휘와 단계별 집계 |
| `deploy/` | 직접 서버에 올릴 때 쓰는 Docker·nginx 설정 |

- **배포:** `main` 브랜치에 올리면 GitHub Actions가 테스트와 빌드를 거쳐 GitHub Pages에 배포합니다.
- **글감 추가:** `src/app/texts.ts`에 한 줄씩 넣습니다. 기본 배열로 칠 수 없는 글자가 섞이면 테스트가 알려 줍니다.

자세한 구현 기록은 [docs/DEVELOPMENT.md](docs/DEVELOPMENT.md)에 있습니다.
