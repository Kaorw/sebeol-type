# 개발 기록

신세벌식 P2 자판 타자 연습 — https://kaorw.github.io/sebeol-type/

신세벌식 P2 기본 배열 자판연습 사이트의 핵심 로직. 화면은 1단계에서 붙인다.

## 구성
- `src/hangul/jamo.ts` — 음절 조합/분해, 겹홀소리·겹받침·된소리 표
- `src/layout/p2.ts` — P2 기본 배열 (KeyboardEvent.code → 낱자)
- `src/layout/physical.ts` — 물리 배열(일반/오쏘리니어/스플릿/Ergo)과 손가락 배정
- `src/layout/semoe.ts` — 세모이 기본 배열과 모아치기 결합 규칙(요즘 한글)
- `src/engine/semoe.ts` — 세모이: 키 묶음 → 글자, 글자 → 권하는 키 묶음, 받아 주는 조합 판정
- `semoe.html` + `src/semoe-ref.ts` — 세모이 전체 배열·결합 법칙 안내 페이지. 표는 `chordFor`/`otherChords`로 만든다. 일반 빌드에만 들어가고 `build:single`에는 빠진다
- `src/scheme.ts` — 자판(P2/세모이) 묶음. 화면·출제·통계는 고른 자판만 본다
- `src/engine/automaton.ts` — 정방향: 키 → 글자 (첫가끝 갈마들이)
- `src/engine/reverse.ts` — 역방향: 글자 → 키 순서 (하이라이트용)
- `data/vocab-raw.txt` → `data/vocab.json` — 정제된 어휘
- `scripts/vocab-stats.ts` — 해금 단계별 낱말 수 집계 → `data/vocab-stats.txt`
- `data/freq/*.txt` → `scripts/build-freq.ts`(`npm run vocab:freq`) → `data/vocab-freq.json` — 「현대 국어 사용 빈도 조사」 일반어·고유명사·조사·어미
  - 항목 열만 쓰고 동음이의어 번호(감자05)는 뗀다. 한글 음절만으로 된 항목만 남긴다(기호·숫자·낱자 섞인 298개 버림)
  - 같은 낱말은 빈도를 더해 하나로, 빈도 내림차순. 학습용 어휘와 겹치는 5,539개는 뺌 → 64,060개
  - 출제: 학습용 어휘 다음에 빈도 차례로 이어 붙인 순위(rank 0~1)를 두고, 안 나온 낱말끼리는 `무작위 + 순위×3`으로 골라 자주 쓰는 낱말이 먼저 나온다

## P2 입력 규칙 (엔진 구현 기준)
1. 오른손 키 = 초성. 초성만 있을 때 같은 키를 또 치면 된소리(ㄱ ㄷ ㅂ ㅅ ㅈ).
2. 초성만 있을 때 `/ O I` 는 오른쪽 홀소리 ㅗ ㅜ ㅡ.
3. 초성만 있을 때 왼손 키는 가운뎃소리(갈마들이).
4. 오른쪽 홀소리 다음 왼손 키가 겹홀소리를 이루면 겹홀소리(ㅘ ㅙ ㅚ ㅝ ㅞ ㅟ ㅢ), 아니면 받침.
5. 왼쪽 홀소리 다음 왼손 키는 받침 (예: K V F = 곺).
6. 받침 다음 왼손 키는 겹받침(ㄱㄱ→ㄲ 포함), 안 되면 받침 낱자만 새로.
- 규칙은 pat.im 온라인 한글 입력기(ohi.pat.im/?ko=sin3-p2)에 같은 키를 친 결과와 대조함.
- 역방향은 홑홀소리 ㅗ ㅜ ㅡ를 왼손(V B G)으로 낸다.

## 알려진 점
- `data/vocab-raw.txt`는 프로젝트 문서 「한국어 학습용 어휘 목록.txt」를 중복 없이 옮겨 적은 것. 배포 전 원본 파일로 교체 권장.

## 1단계 MVP (화면)
- `npm run dev` — 개발 서버
- `npm run build` — 홈랩용 정적 파일 → `dist/` (아무 웹서버에 그대로 올리면 됨, 상대 경로 빌드)
- `npm run build:single` — 파일 하나짜리 → `dist-single/index.html`
- 해금: 1단계 기준 자리(홈 행 + ') → 2단계 + 윗줄 → 3단계 + 아랫줄
- 해금 조건: 열린 키가 모두 표본 10타 이상, 숙련도 80% 이상 (숙련도 = min(1, 키 속도/목표 속도) × 정확도, 최근 30타 기준)
- 진도는 브라우저 localStorage(`sinsebeol-p2.v1`)에 저장

## 2단계 (다양화·짧은 글)
- 낱말 출제: 한 차례 안 중복 없음, 가장 오래 안 나온 낱말부터, 집중 키 낱말은 1/3까지(직전 2차례에 나온 것 제외). 낱말별 마지막 출제 차례를 저장.
- 짧은 글 모드: `src/app/texts.ts` — 직접 쓴 문장 70개 + 전래 속담 40개. 한글·띄어쓰기·쉼표·마침표만 사용(기본 배열, 윗글쇠 없음). 오래 안 나온 글감부터 70자 이상 묶어 출제.
- 짧은 글 모드에서는 모든 키가 열리고, 해금 판정은 낱말 모드에서만 한다(키별 기록은 두 모드 모두 쌓임).

## 3단계 (공개용)
- 숫자 줄과 Shift 키를 물리 배열에 추가. 숫자, 쉼표, 마침표, `?`(Shift+/), `!`(Shift+1), `:`(Shift+;) 입력 (OHI로 확인).
- 짧은 글 "내 글감": 붙여 넣은 글은 이 브라우저의 localStorage(`sinsebeol-p2.mytexts`)에만 저장, 사이트 파일에는 들어가지 않음. 칠 수 없는 글자는 빼고 알려 줌.
- 통계 화면: 키별 숙련도 지도(키보드), 최근 30차례 속도·정확도, 키별 기록 표(약한 키부터), 기록 지우기.
- 해금 켬/끔: 끄면 키 칩을 눌러 연습할 키를 직접 고름(칠 수 있는 낱말이 5개 미만이 되면 막음).
- 공개 시 출처 표기(바닥글): 신세벌식 P2(팥알, pat.im), 국립국어원 「한국어 학습용 어휘 목록」(공공누리 제1유형), 짧은 글(직접 쓴 문장·전래 속담).

## 글감 (짧은 글)
- `src/app/texts.ts`: 직접 쓴 생활 문장 70 + 새 한 줄 문장 84 + 전래 속담 40 + 저작권 만료 문학 38 = 232개
- 문학 원문: 위키문헌 — 현진건 「운수 좋은 날」(1924), 김동인 「배따라기」(1921), 나도향 「벙어리 삼룡이」(1925, 현대 표기로 옮김). 따옴표·한자 병기는 빼고 줄표는 쉼표로 바꿈.
- 연습 글 아래에 그 차례 글감의 출처를 표시. 글감 선택: 전체 / 문학 / 한 줄 / 속담 / 내 글감.

## 세모이(모아치기) 모드
- 자판 고르기: 머리의 `자판` 단추, 또는 주소에 `?scheme=semoe`. 자판을 바꾸면 페이지를 다시 읽는다.
- 기록은 자판마다 따로 저장한다(`sinsebeol-p2.v1` / `semoe.v1`). 물리 배열 선택은 함께 쓴다(`sebeol-type.layout`).
- 한 글자 = 한 타: 키를 누르는 동안 모으고, 모두 떼는 순간 판정한다. 글자 키와 스페이스를 함께 누르면 띄어쓰기까지 친 것으로 본다.
- 속도(타/분)는 맞게 친 글자의 낱자 키 수로 센다. 키별 숙련도는 글자에 든 키마다 기록한다.
- 결합 규칙: OHI 세모이 구현(`K3_Semoe_combination_table`)의 차례를 그대로 따른다. 옛한글이 되는 규칙은 결과 `x`로 남겨 판정 차례를 지킨다.
- 권하는 조합: 가장 적은 키 → 같은 손가락 두 키 피함 → 보조키(`;` `.`)를 쓰는 조합 순.
- 권하는 조합이 아니어도 되는 조합(예: 과 = K V F)은 받아 준다. 세모이 타자연습(semoi-typing.pages.dev)이 받지 않는 3키 ㅞ 등 9개는 뺐다.
- 대조: 낱말·글감의 음절 1,022개를 권하는 조합으로 세모이 타자연습에 쳐서 모두 같은 글자가 나옴(2026-09-28).
- 해금 단계: `;`(받침 ㅆ)은 홈 행 키지만 홈 행만으로 칠 수 있는 낱말이 없어 2단계(윗줄)에서 연다. 낱말에 한 번도 안 나오는 키는 해금 판정·집중 키에서 뺀다(테스트로 단계마다 키당 낱말 3개 이상 확인).
- 약어(줄임말)·옛한글·기호 확장은 아직 다루지 않는다.

## Ergo 배열
- 사진으로 본 열 엇갈림 스플릿 키보드의 글자 영역만 옮김. 모델 정보 없이 사진만 보고 옮겨 크기는 어림값.
- 맨 아랫줄(Ctrl·Opt·⌘·Fn1·엄지 키·노브, ←·M1~M3·트랙볼)은 그리지 않는다. 대신 스플릿 배열처럼 양쪽에 작은 스페이스바(2u)를 하나씩 둔다.
- 열 높이: 가운데손가락 열(E, I)이 가장 높고, 새끼 열이 가장 낮다.
- 손가락: Q·A·Z 왼새끼, W·S·X 왼약지, E·D·C 왼중지, R·F·V·T·G·B 왼검지 / Y·H·N·U·J·M·오른쪽 B 오른검지, I·K·, 오른중지, O·L·. 오른약지, P·;·- 오른새끼.
- 이 배열에는 `'` `/` 키와 오른쪽 Shift가 없다. P2의 ㅌ(') ㅋ(/)는 화면에 자리가 없다는 안내가 뜬다.
- 예전 id `split-tb`로 저장된 설정은 `ergo`로 옮긴다.

## 낱말 출제와 키 기록
- 키별 need(0.05~1.5): 표본이 모자라면 1, 아니면 `0.05 + 0.6×(1−숙련도) + 1.0×(1−정확도)` (`stats.ts` `needOf`).
- 낱말 무게 = `(0.1 + 가장 큰 need + 0.5×평균 need) × e^(−4×순위)`. 직전 2차례에 나온 낱말을 빼고 무게에 비례해 겹치지 않게 뽑는다(Efraimidis–Spirakis).
- 틀렸을 때 기록: 이어치기는 잘못 누른 키, 모아치기는 빠뜨리거나 더 누른 키에만 오타를 남긴다. 키는 맞고 Shift만 틀렸으면 그 키에 남긴다.
